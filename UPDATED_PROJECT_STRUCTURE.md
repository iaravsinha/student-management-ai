## Notable Changes

- Central permissions live in `backend/app/core/permissions.py`.
- Mutating/error API requests and AI actions are recorded in `audit_logs`.
- Bulk student Excel import is handled by `POST /students/import`.
- AI query handling now returns a structured command object and can execute allowed attendance operations.
- The attendance UI uses a checkbox roster with Mark All and Unmark All.
- Frontend navigation reads backend permissions through `/auth/permissions`.
